# Qui paie une réforme des retraites ? (travail en cours)

Valeur actualisée, par âge, de trois réformes de même rendement budgétaire : baisse des pensions, hausse des
cotisations, recul d'un an de l'âge de départ. Modèle : `model.py` ; contrôles : `check.py` ; figures : `figures.py`.

**Attention : les fichiers de `data/` sont pour l'instant des données de test synthétiques (`data/calage.json`,
clé `provisoire`), en attendant le calage sur les séries Insee, DREES et COR. Aucun résultat n'est à lire.**
