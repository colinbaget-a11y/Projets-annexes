DGCL-DGFiP, note REI 2025 ; OFGL ; SDES, Compte du logement 2025 ; DGFiP Statistiques n° 43 ; calculs de l'auteur (foncier/notes/inventaire.md).\par Note : rendements 2024, périmètres hétérogènes. TF : taxe foncière sur les propriétés bâties (42 Md\euro{}, dont 30,5 sur les logements selon le Compte du logement ; le reste par différence, non vérifié) ; TEOM : taxe d'enlèvement des ordures ménagères ; CFE : cotisation foncière des entreprises. Autres de la détention : taxes d'habitation restantes, IFI, foncier non bâti, taxe sur les bureaux d'Île-de-France, GEMAPI, taxes spéciales d'équipement. Ventes : droits de mutation, TVA du neuf et des terrains, impôt sur les plus-values immobilières et contribution de sécurité immobilière. Transmissions : part immobilière des droits de succession et de donation, estimée à 60 \% (clé du CPO, aucune ventilation officielle).
